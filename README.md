# npm scripts
### Start api server
```
npm run start
```

### Clear any table in db
```
npm run clear-table $TABLE_NAME
```

### Clear schedule cache in running docker container
```
npm run clear-cache                    # whole cache
npm run clear-cache $GROUP_ID          # cache of one group
npm run clear-cache $GROUP_ID $USER    # cache of one group for one user
```
